# C线：稳健强反弹升级线

## 目录

- `data/`：该策略所需的干净 ETF 数据、池子和质量检查信息。
- `config/`：策略配置。
- `src/`：可继续研究和复核的核心脚本。
- `results/`：正式结果、交易表、年度表或摘要。
- `live/`：若存在，则为最近一次实盘/每日决策输出。

## 数据说明

本目录内放置 C 线使用的 30 只干净 ETF 日线数据。

## 结果说明

正式升级摘要在 `results/clean_upgrades/summary.json`，交易表和年度表同目录。

## 复核建议

先看 `results/` 中的摘要文件，再查看交易明细。若要继续调参，优先复制本目录为新实验目录，不要直接覆盖正式结果。
