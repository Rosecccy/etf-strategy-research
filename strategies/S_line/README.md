# S线：趋势补充线

## 目录

- `data/`：该策略所需的干净 ETF 数据、池子和质量检查信息。
- `config/`：策略配置。
- `src/`：可继续研究和复核的核心脚本。
- `results/`：正式结果、交易表、年度表或摘要。
- `live/`：若存在，则为最近一次实盘/每日决策输出。

## 数据说明

本目录内放置 S 线扩展 ETF 池的干净日线数据；此前异常 ETF 已通过质量文件标记。

## 结果说明

正式选择器摘要在 `results/selector/summary.json`，净值交易和年度选择表同目录。

## 复核建议

先看 `results/` 中的摘要文件，再查看交易明细。若要继续调参，优先复制本目录为新实验目录，不要直接覆盖正式结果。
