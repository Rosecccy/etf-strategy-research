# 14:45 同日执行 V2 冻结基线

这是 2026-08-21 从完整审计压缩包中提取并冻结的 14:45 决策、当日执行版本。GitHub 中保存的是可审查的正式结果与因果选择证据，不把全样本最优结果包装成样本外结果。

## 固定规则

- 以既有 C/S/D/R 正式信号账本为输入，不重新挑选指标或 ETF。
- 每个测试年度只使用更早年度的数据选择策略；测试年度数据不会参与当年选择。
- 历史 14:45 回测使用日线收盘价作为代理。原始数据没有分钟级 14:45 成交价，因此不能声称还原真实盘中成交价。
- C/S/R 为单仓复利口径；D 保留原研究账本的逐笔收益合计口径。
- 同日卖出后换仓允许；真正的单仓重叠不允许。
