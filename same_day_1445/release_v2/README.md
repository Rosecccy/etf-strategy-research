# 14:45 同日执行 V2 冻结基线

这是 2026-08-21 从完整审计压缩包中冻结的 14:45 决策、当日执行版本。GitHub 中保存可审查的正式结果、C/S/R 逐笔冻结账本、D 年度与跨年边界证据，以及年度因果选择证据，不把全样本最优结果包装成样本外结果。

## 固定规则

- 以既有 C/S/D/R 正式信号账本为输入，不重新挑选指标或 ETF；
- 每个测试年度只能使用更早年度选择策略；
- 历史 14:45 回测使用日线收盘价做代理，不能声称还原真实盘中 14:45 成交价；
- C/S/R 为单仓复利口径；D 保留原研究账本的逐笔收益合计口径；
- 同日卖出后换仓允许，真正的单仓重叠不允许。

`selected_choices.csv` 现在显式保存每个测试年度的 `train_years` 等因果证据。`selected_trades_csr.csv` 保存 C/S/R 的 126 笔逐笔冻结交易；`d_annual_compact.csv` 按实际入场年份汇总 D 线；`d_cross_year_entry_audit.csv` 保存 6 笔已知跨年移动交易的边界证据。

D 的提升主要来自平均单笔收益和最大回撤改善，不是胜率大幅提升。由于 D 使用 research-sum 口径，其“期末资金”不能与 C/S/R 的单仓复利资金直接横比。

## D 线年度定义

跨年移动交易统一按有效执行后的 `entry` 年份统计：

- `year` / `entry_year` = 实际入场年份；
- `source_year` = 原始账本 `old_entry` 年份，仅用于追溯。

因此 D 的年度汇总与 `selected_choices.csv` 的测试年份采用同一口径。
