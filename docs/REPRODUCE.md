# 复核说明

本包目标是复核和继续研究当前四条策略，而不是保留所有历史淘汰实验。

## 数据口径

- 使用本包内 `data/etf/*.csv` 的干净 ETF 日线数据。
- 已剔除或不纳入此前发现异常跳变、除权不干净、重复度过高或不适合落地的数据。
- 每条策略的具体执行口径以该策略目录下 `README.md` 和 `config/` 为准。

## 严格滚动原则

正式策略不允许使用未来年份选择当年参数。历史回测中的候选选择、阈值选择、退出保护等，必须只使用该测试年前已经完成的数据。

## 文件完整性

运行：

```powershell
python scripts/verify_package.py
```

并可用 `file_manifest_sha256.csv` 做逐文件哈希校验。
